# v0.3 交互修订与验证记录

日期：2026-09-06。已先更新需求与交互文档，再完成对应前端代码；本轮六项修改均已实现。

## 实现范围

- 浅色／深色界面切换，保存用户偏好；图像、几何与导出图保持自身颜色。
- 物体卡片独立折叠，选中状态不再强制展开某一张。
- 录制结果、缩略图、放大预览及导出使用同一条最新轨迹。
- 预选录制目标期间仍可自由观察；开始录制才激活物体控制器。
- 鼠标 yaw／pitch 与 Q/E roll 分离，pitch 限制 ±89°；透视投影不变。
- 新增一个球头、方块躯干和四肢的人物整体对象，初始静止。

## 回归检查清单

1. 切换浅／深主题检查全部表单、时间轴、弹窗及视口 HUD；刷新保留选择。
2. 两张以上物体卡片可同时展开，也可全部折叠；选中和提示词不丢失。
3. 对已有轨迹物体重新录制一条不同轨迹，结束后卡片和放大图立即更新；保存、导出、刷新仍是新结果，旧轨迹在历史中。
4. 点击物体“录制”后进入视角控制，只有观察相机移动；正式开始前物体不被键鼠改变。
5. 反复组合鼠标偏航／俯仰及平移，不产生未输入的横滚；Q/E 主动横滚保留，基向量正交，俯仰受限。
6. 人物首帧／mask／点云一致，可选正面、录制、静止、回放和导出；旧示例升级幂等且保留历史，外部项目不被改动。

## 旧示例升级与存储配额

浏览器验收发现旧工作区的 localStorage 无法再容纳第二份恢复副本。升级需先尝试独立 localStorage 备份，配额不足时改用 IndexedDB 的恢复备份事务；只有事务完成后才允许覆盖当前工作区键。备份失败则继续保留旧工作区，界面明确仅当前会话／请导出，不静默覆盖。此处 IndexedDB 仅用于恢复副本，不表示已实现正式服务端同步。

失败后的后续编辑不得再次显示“正在备份”，除非实际启动重试。同一项目主动重新载入演示场景时，需重新初始化渲染器并生成首帧和 mask，不依赖示例格式版本变化。异步导入首帧绑定发起导入的项目，不能因读取期间切换项目而写入另一个项目。

## 验证记录

自动回归覆盖录制结果和 PNG 的同步替换、旧轨迹历史、预览失败不覆盖结果、最新预览引用、保存序列化、独立观察视角、六种物体正面、俯仰限制和示例升级。构建与完整测试结果汇总见 [使用说明的验证章节](prototype-guide.md#验证)。

浏览器实际检查：

- 浅／深主题下检查主面板、卡片、时间轴、HUD 与预览弹窗；刷新后保留深色选择，科学轨迹 PNG 保持原配色。
- 同时展开两张物体卡片，再全部折叠；折叠不撤销物体选择。
- 在独立测试项目中选择人物正面、预选录制并进入视角控制，仍显示自由观察；主面板开始录制才进入人物录制状态。
- 人物第一次录制得到 5 秒、302 个样本，再次录制得到约 0.604 秒、38 个样本。结束后卡片、时间片段、放大 PNG 同步更新为后一次结果，刷新后仍为 38 个样本。该浏览器检查验证了重新录制与保存闭环；工具未持续产生平移／鼠标转向输入，这两次录制不作为非零运动的端到端证据。
- 旧示例增加人物后保留已有物体和相机轨迹。实际遇到 localStorage 备份配额不足，IndexedDB 恢复副本提交后恢复本机自动保存。

横滚问题的回归复现表明：旧局部四元数增量即使始终产生正交旋转矩阵，连续组合偏航与俯仰也会累积横滚；测试中的往返操作约累积 −3.366°。修复将 yaw、pitch、roll 分开维护，再以固定顺序生成归一化四元数；相同操作不再产生额外横滚，Q/E 仍可主动横滚。保留透视投影，俯仰按 D21 限制为 ±89°。

持续真实鼠标与键盘组合操作仍建议由用户在桌面浏览器体验确认；数学与状态回归不替代原生输入体验。真实 SAM、单图重建及 CE 模型服务仍不在本轮实现范围。
