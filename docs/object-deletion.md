# 物体控制面板：删除物体

修订：2026-09-11。先明确本节行为，再实现代码。

## 交互与数据范围

- 每张物体卡片标题旁增加「删除物体」按钮，收起卡片时也可操作；按钮具有包含物体名称的提示和无障碍标签。待处理、失败的物体定义也提供同一入口。
- 删除前确认物体名称和影响：从当前项目移除物体定义、分割显示、3D 包围盒、当前轨迹、时间片段与该物体的轨迹历史。取消确认不修改项目。
- 删除只改变项目中的物体实例。原始 Depth Pro 场景保留，被解除关联的点重新作为静态背景显示；首帧、SAM2 候选、关联作业、日志和模型产物保留。集群运行任务继续执行，删除不会提交或取消 GPU 作业，也不会删除服务器文件。
- 待处理物体删除后，不再自动加入场景；保留提交记录以便确认网络状态不明的请求。以后需要重新定义时，可重新选择候选、填写名称并提交关联。
- 本机自动保存删除后的项目，刷新和项目切换后保持。集群项目快照沿用显式「保存或导出项目」操作；旧快照不自动改写。本次不新增独立的物体回收站，需要保留原轨迹时请先保存项目副本或下载轨迹。
- 录制倒计时、录制、暂停待保存、轨迹保存、项目交换等既有锁定状态下禁用删除。

## 联动与异步一致性

1. 同时删除 `objects` 中的实例与 `workflow.objectDefinitions` 中同 ID 的自动应用定义，防止轮询或刷新后重新添加。自动应用结果的函数式更新还须重新校验定义仍在当前项目中，拒绝删除前排队的回调。
2. 清理指向该物体的选中、时间轴、录制准备和轨迹预览状态；停止场景播放并回到首帧。保留其他物体及相机轨迹，动态场景已构建时标记为待更新。
3. 清除当前 `workflow.exportJobId` 绑定，后续生成需重新导出并填入 SymphoMotion Rendered Frames。历史导出、生成记录和已提交请求快照保持原状。
4. 删除最后一条物体轨迹后，物体控制自动关闭。仍有物体轨迹时保持用户原来的开关选择，包括手动关闭状态；删除不应意外开启其他物体的 OMM。相机控制选择保留。
5. 其他正在关联的任务如依赖删除前的物体集合，继续由既有集合校验拒绝自动应用过期结果，提示重新关联以检查重叠。

## 验证计划

- 验证删除已关联物体、待处理定义、最后一个物体、未知 ID；其他物体、相机、提交记录与源场景不受影响。
- 验证旧关联回调不会恢复已删除物体，新的显式关联仍可使用。
- 验证点云归还背景、导出失效以及控制开关联动。
- 使用隔离浏览器工作区验证取消／确认、收起卡片删除、切换与刷新持久化、最后物体的空面板和参数开关；保留截图及结果于 `var/validation/20260911-object-deletion`。
- 运行相关前端测试和构建；本次不修改 Conda 环境、不进行模型推理。

## 实施与验收结果

已实现并构建到当前 `8000` 服务使用的 `dist/`；刷新页面即可使用。无需重启后端，未修改任何模型环境或用户正式项目。

- 前端常规测试 **181 项通过**；默认跳过的真实点云用例指定历史产物后单独运行通过，合计 **182 项通过**。覆盖实例／待处理定义删除、异步旧回调、控制开关、导出失效及原始点回归背景。TypeScript 与生产构建通过；构建保留已有 Node 版本和包体积提示。
- Firefox 隔离工作区使用现有真实关联作业，原生点击验证收起卡片上的删除按钮、确认取消、清理录制准备目标、最后物体删除、刷新后两次以上轮询、项目切换与待处理定义删除。删除前后的集群关联作业及产物列表一致，未提交或取消 GPU 作业。
- 原有导出在删除前可执行生成；删除后生成按钮禁用并提示重新导出。物体控制自动关闭，相机轨迹与相机控制保留。
- 无头 Firefox 没有 WebGL2 上下文，浏览器验收覆盖真实 DOM 交互和项目状态；点云归还背景由几何单元测试验证，历史真实产物另验证解码与场景组装。截图不作为 3D 像素渲染验收。

复现入口：`scripts/validate-object-deletion-browser.py`。测试仅在专用浏览器配置中写入项目副本；初始化新用例时先离开应用页面，避免自动保存覆盖测试数据。
