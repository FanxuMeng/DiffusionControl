# v0.4 物体参考轴与滚轮调速

日期：2026-09-06。按先文档、后代码的顺序实施。D22／D23 已询问，尚未收到回复；本轮先采用下述明确标注的推荐方案，收到选择后调整，不视为用户确认。

## 物体中心参考轴

- 在 3D 视图中，每个已分割物体的 bbox 中心显示参考轴；轴随当前物体位姿更新，录制、播放和时间定位使用同一位姿。
- 坐标轴与 bbox 随“包围盒”开关一起显示／隐藏，不写入首帧、mask 或重建数据。
- object-card、bbox 六面和参考轴使用同一个配色定义，以当前卡片颜色为准：+X `#ec8b7f`、−X `#ad6367`、+Y `#96b59a`、−Y `#587d70`、+Z `#91acd8`、−Z `#686caa`。物体实例标识色独立保留。
- 所有可见 bbox 显示六向箭头，选中对象另外显示紧凑的 ±X／±Y／±Z 标注；卡片明确说明这些是 bbox 参考轴。投影接近重叠时错开文字并用引线连接真实轴端，避免标签遮住坐标轴。轴长按 bbox 尺寸确定。
- D22 暂按推荐方案：显示 bbox 的六向参考轴，初始与原 bbox 六面一致，运动时按 `R(t) R(0)⁻¹` 随物体变换；中心为当前物体位置。选定正面定义物体局部 +X，但不重命名原 bbox 六个面。单独的正面箭头用于提示局部 +X，卡片需区分这两个参考系。

## 滚轮调速

- 进入 3D 视角控制后，上滚提高平移速率，下滚降低；改变的是 WASD、Shift／Control 合成后的速率，不改变鼠标灵敏度、Q/E 角速度、FOV 或时间轴播放倍率。
- 仍然松键即停；原地滚轮只修改下一次移动的设定速率，不产生位移。录制中改变速率由带时间戳的位置样本自然体现，不重新定时已有轨迹。
- 原型沿用设置面板的 `0.01–8 su/s` 范围，默认 `0.35 su/s`。每个标准滚动单位上滚乘 1.2、下滚除以 1.2；100 CSS 像素、3 行或 1 页等价于一个标准单位，触控板小增量按比例累计。滚轮与设置面板修改同一速率，HUD 同时区分“设定平移速率”和“当前实际速率”。这些步幅与界限为可后续调整的原型默认值。
- 仅在 3D 视口拥有 Pointer Lock 且处于可移动的预览／录制状态时接收调速。未进入控制、2D、暂停、倒计时、跟随已录相机回放、面板输入或普通页面滚动均不触发；浏览器 Ctrl／Meta 滚轮缩放不作为调速输入。
- HUD 操作提示同步可用状态；参考轴文字属于非交互标注，不增加无作用的 Tab 停靠点。
- D23 暂按推荐方案：滚轮作用于所有受控平移，含自由观察、相机录制与物体录制。预选物体后自由观察仍只改变观察相机的设定速率，不提前驱动物体。

## 数据边界

参考轴是现有 bbox／位姿派生的可视化，无需改变轨迹坐标或项目几何版本。滚轮改变当前会话控制设置，轨迹仍保存真实时间和位姿；无需为了回放另外存储滚轮事件。正式录制偏好及后端序列化继续按项目格式文档规划，不能把当前原型的会话设置声称为已同步到 CE。

## 验证计划

1. 检查三处颜色一致、中心原点准确、所选正面与参考系意义明确；平移／旋转／时间定位时参考轴跟随正确。
2. 检查上／下滚方向、比例、限值及不同 deltaMode；连续小滚动与合并事件结果一致。
3. 检查松键停止、斜向归一以及调速不修改旋转或历史轨迹；确认非受控状态与浏览器缩放不接管滚轮。
4. 检查构建、相关回归及浏览器中的轴和速度显示；记录实际原生输入验证范围。

## 验证结果

- 生产构建通过；12 个测试文件、75 项测试通过。新增 3 项参考轴回归和 5 项滚轮回归，覆盖当前两项修改及其与既有位姿／运动规则的衔接。
- 浏览器已检查点云中中心轴、卡片同色按钮与速度 HUD；未进入控制时滚动视口，设定仍为 0.350 su/s，实际仍为 0。
- 检查时发现轴端标签相互遮挡，随后改为紧凑标签、错开布局及引线。后续浏览器自动化暂无法取得有效界面树／截图，因此新版标签布局、Pointer Lock 下上／下滚调速和持键组合移动的原生输入验收未完成；不将纯函数回归当作这部分浏览器证据。
- 本轮不改写项目轨迹／几何数据格式，不触发示例升级；用户既有项目和轨迹保持原有存储语义。D22／D23 的选项仍可在用户答复后调整。
