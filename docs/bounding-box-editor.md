# 3D 包围盒编辑与相机轨迹删除

修订：2026-09-11。本轮先写文档，再修改代码。

## 3D 编辑交互

在 3D View 中选择已关联物体，进入「编辑包围盒」。视口显示平移、旋转、尺寸三种操作工具，以及局部相对位移、完整边长与局部相对旋转输入；鼠标拖动控制柄或输入数值时实时预览。提供应用、取消及恢复本次编辑起始值。

编辑针对首帧的包围盒。进入时停止播放、退出录制准备和相机跟随并回到时间零；编辑期间暂停项目切换、轨迹录制和工作流自动应用。拖动框不会触发原有「选择物体正面」交互。应用前草稿不写入项目；取消保留原值。编辑时保留观察场景的操作，便于从不同方向调整。

用户已确认：按新框重新筛选点簇，成功后清除当前物体轨迹，重新定义运动。

### 重新筛选与任务状态

- 从完整重建场景选择位于编辑后有向框内的点，可扩大或缩小物体范围；排除其他物体已经占用的点，保持点集互斥，并记录排除数量。保留稳定的原始像素／点 ID、RGB、OpenCV 世界坐标以及参考相机标定。边界采用浮点容差，至少保留 9 个有效点；空框或点数不足视为任务失败。
- 重新选择保留用户指定的中心、边长与朝向，不再次自动拟合改变用户的框。新关联产物的中心与新初始位姿一致，因此沿用现有 SymphoMotion 导出与点簇变换规则。
- 复用 `associate` 任务、全局 sbatch 脚本及关联面板 ENVNAME；扩展 `inputs.replaceObjectJobId` 和 `options.selectionBox`。仍保留原 SAM2 作业／候选作为来源记录，新选择以 3D 框为准。服务端验证被替换作业归属、首帧、场景与来源，以及框参数合法性。
- 提交前把带 `replaceObjectJobId` 的物体定义与请求一起持久化。原实例在成功前保留，面板显示等待／运行状态并暂停该物体的运动编辑。刷新后继续跟踪；失败可放弃本次更新，原点簇和轨迹不变。删除物体或放弃更新后，迟到的结果不自动恢复物体。
- 只有当当前物体仍引用提交时的旧关联作业、其余物体集合仍一致时才原位替换。物体稳定 ID、名称、描述、颜色、正面选择保留；当前轨迹与 clip 清空，旧轨迹存入历史，原运动物体变为待定义。相机轨迹保留。
- 新产物继续使用 `object.npz`、`preview.bin`、`point-ids.bin`、`mask.png`、`overlay.png`、`result.json`，存入同一项目的新作业目录。旧作业及文件不改写。
- 成功后将动态场景标记待更新，清除 Rendered Frames 绑定；历史轨迹仍可导出，但旧起点与新框不一致时不能直接重新应用，需要重新录制或使用对齐新框的预设。

### 坐标与交互实现

Three.js `TransformControls` 操作单独的草稿对象，父级使用现有 OpenCV → Three.js 变换 `BASIS`。框尺寸为局部完整边长，持久化仍使用半尺寸；旋转保存归一化四元数。禁止零／负尺寸和非有限值。

三个拖拽工具和数值输入统一使用当前包围盒的局部 XYZ 轴，不以世界坐标轴或进入编辑时的初始框朝向作为后续操作的基准。

- 「相对位移」沿当前框局部轴平移，单位为场景单位；「相对旋转」绕当前框局部轴、以框中心为轴心旋转，单位为度。边长仍是框自身 XYZ 方向的完整长度，调整尺寸不改变框中心或朝向。
- 每次聚焦一个相对输入框，记录当时的草稿作为本次操作起点。输入时由这个起点计算预览，避免依次输入 `1`、`12` 时误累计成 `13`。回车或离开输入框即保留最后一次有效预览，并将该增量输入归零；下一次输入使用更新后的框坐标系。空值／非有限输入时暂停提交，离开相对输入框后恢复零增量，保留最后有效预览。取消仍放弃整个草稿，重置恢复进入编辑时的框并复位所有输入。
- 若当前中心为 `c`、朝向为 `q`，局部平移 `d` 对应 `c' = c + R(q) d`；绕某条局部轴的增量旋转为 `q' = normalize(q × q_delta)`，中心不变。旋转不使用世界轴四元数左乘，也不将局部增量覆盖为绝对欧拉角。不同轴的数值编辑按操作顺序依次执行。
- 例如框绕场景 Z 轴旋转 90° 后，局部 X 平移 1 单位应沿场景 Y 移动 1 单位。再次旋转后，后续平移使用新的局部轴。
- 前端最终仍提交场景坐标中的 `selectionBox.center`、半尺寸及四元数，后端框内选点公式和项目文件格式保持兼容，无需迁移已有项目。

草稿工具只改变框，原始点云保持首帧姿态。应用后待新关联完成再切换点簇资源，避免把预览框误当作已经修改的物体。每次更换点簇作业 ID 都重新加载相对新中心的预览，避免复用旧中心偏移。

已发现的链路约束：当前前端将点簇坐标相对拟合中心缓存；导出 worker 还要求初始位姿中心等于关联产物的拟合中心。允许用户编辑中心后，必须同步处理预览坐标和导出校验，不能只改变框线外观。

## 相机轨迹删除

- 相机控制面板标题旁增加「删除相机轨迹」按钮，有当前轨迹时显示，面板收起后仍可点击。录制、项目交换或包围盒编辑等锁定状态下禁用。
- 确认后清除当前相机轨迹和对应时间片段，并把该轨迹保留到现有相机历史列表。用户可从「轨迹预设 → 历史轨迹」重新应用；首帧标定和固定镜头参数保留。
- 退出相机跟随、清理相机录制准备和时间轴选择、关闭对应轨迹预览，停止播放并回到首帧。
- 相机控制开关自动关闭，物体及其运动不变，4D 场景状态不因相机轨迹删除而失效。
- 清除当前 Rendered Frames 绑定，后续生成须重新导出。已提交的集群作业、历史导出和生成产物保留。
- 沿用项目本机自动保存和显式保存集群快照机制，不改写旧快照。

- 相机删除的取消、确认、历史恢复、控制开关、导出失效及刷新持久化。
- 包围盒平移／旋转／尺寸编辑的坐标正确性、草稿取消、项目恢复、物体运动和导出兼容性。
- 使用已有点云及模型环境，不安装新依赖。浏览器及几何验收结果保存到项目内 `var/validation`；若需模型测试，仍通过 sbatch 执行。

## 使用步骤

1. 在物体面板选中物体，切换到 3D View，点击视口工具栏「编辑包围盒」。
2. 选择平移、旋转或尺寸，沿框的局部轴拖动彩色控制柄，或输入相对位移／相对旋转及完整边长。相对输入实时预览，回车或离开输入框后归零；下一次操作基于当前框。需要换视角时点击「观察场景」，使用现有导航按键，按 Esc 返回编辑。取消不提交任务；重置只恢复本次草稿。
3. 点击「应用并重新筛选」。物体面板显示更新任务，刷新后仍可等待。新点簇成功后自动替换原物体；失败可点击「放弃包围盒更新」继续使用原结果。
4. 重新设置物体静止或运动轨迹，更新动态场景，再导出 Rendered Frames。相机原有轨迹保留。
5. 删除相机轨迹使用相机面板标题旁的垃圾桶按钮；需要恢复时打开「轨迹预设 → 历史轨迹」。
